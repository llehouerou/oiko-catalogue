Build 


    
Go 1.27 or later builds it. Put data/config.json below next to oiko, run ./oiko, and open http://localhost:8080.

  


  

    
Dockerfile 

    

    
compose.yaml 

    

    
    
      
  1. Put both files in a directory and run mkdir data there first: Docker would create a missing data owned by root.
    2. 
      
  2. In compose.yaml, set user to what id -u and id -g print.
    3. 
      
  3. Put config.json below in data/. File paths in it are paths in the container: /data/….
    4. 
      
  4. Run docker compose up -d --build, and open http://localhost:8080.
    5. 
    

    

      The container uses the host's network: HomeKit discovers accessories over mDNS.
      To pair one, run docker compose run --rm oiko homekit pair <code>, then docker compose restart.
      When Oiko tells of a newer release, replace the go run command of the Dockerfile with the one it shows, and run docker compose up -d --build again.
    

  


  

    
flake.nix 

    

    
oiko.nix 

    

    
    
      
  1. Add the oiko input and the two modules to your host's nixosSystem in flake.nix, and put oiko.nix next to it.
    2. 
      
  2. Set services.oiko.mqtt to the broker zigbee2mqtt publishes to: the module requires it. services.oiko.settings is the rest of config.json.
    3. 
      
  3. Run nixos-rebuild switch. The first one fails, printing got: sha256-…: set it as vendorHash and rebuild. Then open http://localhost:8080.
    4. 
    

    

      To pair a HomeKit accessory, run sudo -u oiko oiko -data /var/lib/oiko -config /etc/oiko/config.json homekit pair <code>, then systemctl restart oiko.
      When Oiko tells of a newer release, apply the lines it shows and rebuild.
