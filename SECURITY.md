# Security policy

[Oiko's security policy](https://github.com/llehouerou/oiko/blob/main/SECURITY.md) covers this
repository: its response times, scope and disclosure apply here.

Report a vulnerability in the catalogue's jobs, its `index.json` or its site privately, on this
repository: [report a vulnerability](https://github.com/llehouerou/oiko-catalogue/security/advisories/new).
Never in a public issue.

The catalogue lists released types of Bridge without reviewing them: a listing is not an
endorsement. Report a malicious type the same way, here; it is delisted. A bug in a type that is
not malicious goes to that type's repository.
